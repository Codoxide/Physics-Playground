# Inclined Plane Lab — Unity UI Template

Designed from the supplied reference screenshot.

## Unity version
Made for Unity 6 / Unity 6000.x using UI Toolkit.

## Install
1. Unzip this folder.
2. Copy the `Assets/InclinedPlaneLabUI` folder into your Unity project's `Assets` folder.
3. In Unity, create a GameObject and add `UIDocument`.
4. Set its Visual Tree Asset to `Assets/InclinedPlaneLabUI/UXML/InclinedPlaneLab.uxml`.
5. Add `InclinedPlaneLabUIController` to the same GameObject.
6. Press Play.

## What is included
- Dark scientific/lab visual style
- Three-column simulation layout
- Setup controls and sliders
- Running/paused state buttons
- Simulation viewport placeholder
- Force/motion readout panel
- Status badges and net-force card
- Responsive-ish flex layout
- Controller script for Run / Pause / Reset

## Important
This is a UI template, not the actual physics simulation. Replace the placeholder ramp/block/force labels with your existing Unity simulation and connect the controls to your physics variables.

The colors, spacing, typography, cards, controls, and state treatment are intentionally close to the supplied reference.
